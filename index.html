🔥 Key Features

Everything you need for production-ready AI on silicon

🖱️

One-click Model-to-Chip

One command — and you have a binary for FPGA or ASIC. Supports PyTorch, ONNX, and Hugging Face.

⏱️

Hardware Determinism

Strict STDP timing windows guarantee every spike arrives exactly when expected. No jitter, no collisions.

🔒

Hardware Security

The bootloader verifies the firmware signature at boot. Protection against physical attacks and counterfeit hardware.

⚡

CPU-less Boot

Built-in finite-state machine (Loader FSM) loads data from SPI-Flash by itself. No external processor needed.

🏭

Prototype to ASIC in One Flow

Test on FPGA first, then switch to 28-nm production with a single command. GDSII ready in a day.

📦

Pre-compiled Models

TinyLlama, Whisper, YOLO, Stable Diffusion — already compiled. Just download and run.

🛠️ How It Works

Full cycle from model to chip in under 10 minutes

1

Upload Your Model

PyTorch, ONNX, or pick a ready-made one from Hugging Face — TinyLlama, Whisper, YOLO, ResNet.

2

Adaptive BTR Calibration

Automatic spike-threshold calibration retaining >99.2% accuracy of the original model.

3

Phase-Trellis Encoder

Packs data into temporal spikes with minimal latency and maximum density.

4

NoC Routing Map

The compiler builds a Network-on-Chip routing map with virtual channels and hard guarantees.

5

Loader FSM + Binary

Generates a binary for FPGA or ASIC tape-out. The whole process takes <10 minutes for a 1B-parameter model.

🧪 Get Started Now

Install and run in 5 minutes

bash 
# Install
pip install total-neuro

# Convert a model
total-neuro convert --model TinyLlama/TinyLlama-1.1B-Chat-v1.0 --target fpga --output my_chip.bin

# Upload to your FPGA board (if connected)
total-neuro upload --port /dev/ttyUSB0 --bin my_chip.bin
